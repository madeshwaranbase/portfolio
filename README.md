- pytest-xdist
- requests
- Git / GitHub
- GitHub Actions

## Learning approach

The early projects intentionally stay simple. Each later project introduces one or two new ideas instead of hiding everything behind unnecessary abstractions.

## Setup

```bash
python -m venv .venv
```

Windows:
```bash
.venv\Scripts\activate
```

macOS/Linux:
```bash
source .venv/bin/activate
```

For Python projects that need packages:

```bash
pip install -r requirements.txt
```

For Selenium projects:

```bash
pip install -r 11_selenium_login_test/requirements.txt
```

Each project has its own README with run instructions.
